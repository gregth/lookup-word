# Security

Lookup Word holds two macOS permissions, Accessibility and Screen Recording, so a flaw in it can matter beyond the app.
If you find one, please report it privately rather than in a public issue: on GitHub, open the repository's
**Security** tab and choose **Report a vulnerability** (GitHub's private vulnerability reporting). Only the maintainer
sees the report, and the fix and an advisory follow there. If that button is missing, open an issue that asks for a private
contact, with no details of the problem, and the maintainer will reply with one.

Please include the macOS version, the Lookup Word version (the `VERSION` file, or the commit you built), and the steps
that show the problem.

Only the latest version on `main` gets fixes. Lookup Word is a personal project with no support commitment, so a reply
may take a while; reports are still very welcome.
